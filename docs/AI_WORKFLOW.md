## 初始迭代

- 目标：围绕 AI 原生开发实习岗位，搭建需求澄清、验收标准和测试用例审阅的端到端原型。
- 范围：React 工作台、Django API、MySQL/Redis 配置、可选 Anthropic API、演示模式、Markdown 导出和人工修改历史。
- 使用工具：Codex 辅助搭建前后端、接口、配置、测试和项目文档；公开的 Linear 与 Vercel v0 页面/文档用于研究通用交互模式。
- REA 使用情况：初始迭代时未接入 REA；后续 v0 界面刷新已使用 REA 6.4.0 对公开首页做只读观察。证据 ID、观察范围和来源说明见 `UI_REFERENCES.md`。
- 人工判断：将模型输出明确标记为草案；未经审阅的内容不标记为已确认。保留人工修改入口、验收条件、风险提示与版本快照。
- 验证结果：Django 检查通过，迁移检查无待生成文件，后端 4 项测试通过，Vite 生产构建通过；本地浏览器确认工作台、演示需求、验收标准标签和“待人工确认”状态可用。
- 遗留问题：本项目是作品集原型，没有用户认证；Docker Compose 尚未在当前环境执行验证。

## v0 风格研究与工作台刷新（2026-10-15）

- 目标：参考公开 v0 首页的提示输入与模板入口层级，改进 SpecPilot 首页，同时保留现有需求生成、演示和人工审阅流程。
- 使用工具：REA 6.4.0 CLI 被动检查 `https://v0.app/`；Codex 辅助编辑 React/CSS 和项目文档；本地浏览器预览用于交互与响应式检查。
- 观察边界：只分析公开、未登录的首页；通过 loopback CDP 采集 DOM、无障碍名称与视口截图，没有请求脚本源码、存储值或响应体。REA 证据 ID 与来源链接见 `UI_REFERENCES.md`。
- 实现：将首屏改为居中的需求提示框，在输入框下增加三个可点击的场景模板；补强桌面/窄屏字号与间距；保留原来的结果分栏、演示样例、人工审阅、复制和 Markdown 导出逻辑。
- 检查结果：确认模板会填入需求描述并聚焦输入框；打开演示样例后，需求概览、用户故事、验收标准、接口草案、测试用例和待确认问题均可见。检查 1440×1000 桌面视口及 390×844 手机视口，并调整了手机标题换行。
- 验证结果：`frontend` 的 `pnpm run build` 通过；浏览器确认模板和演示样例交互可用。此次本地预览没有启动 Django API，因此真实 API 生成/保存路径不在本次界面刷新验证范围内。
- 设计判断：采用输入优先、模板可选的结构，让没有现成 PRD 的使用者更容易开始；模板只填入可编辑示例，不会替用户自动提交或保存。
